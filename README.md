# 拾光 ShiGuang

不经意地，记录聊天里的美好瞬间——长文、一张图、一段语音，都可能成为多年后的珍藏。

- **纯本地**：不申请联网权限，所有内容只存手机，不上传、不云同步。
- **识别**：通过「通知使用权限」监听微信/QQ 等聊天的通知，用本地规则把消息打分——发图、语音、长文、连发、深夜、特别联系人、命中你在意的主题关键词，都会加权。
- **两种收藏方式**：弹「值得记录的瞬间」一键收藏；开启「授权后自动记录」，高分瞬间直接入库，💙 提醒你。
- **多元回忆**：时间线日记 / 相册墙 / 日历·那年今日 / 随机回忆卡（翻牌动画）/ 关键词·人物检索，外加每晚 21:30 「抽一段回忆」推送。
- **图片归集**：微信图片本体拿不到（平台私有），但你在微信里长按保存后，App 会自动把这张相册图挂到最近的「图片瞬间」上。
- **无障碍增强（可选）**：聊天界面的整段长文也能抓下来留档。

## 构建

**环境**：JDK 17+、Android SDK（platform 34 / build-tools 34.0.0）。工程自带 Gradle wrapper。

```
# 编译 debug APK
./gradlew :app:assembleDebug        # Windows: gradlew.bat :app:assembleDebug

# 产出
#   app/build/outputs/apk/debug/app-debug.apk

# 评分引擎单元测试（6 个判定例子：深夜星标恋人文→自动保存、广告噪声→忽略 等）
./gradlew :app:testDebugUnitTest
```

> 作者在 `C:\Users\Want\dev\ShiGuang` 用本机 `build.bat` 一键构建（内置个人 JDK/SDK 路径，未入库，仅本地）。

> ⚠️ 项目必须位于**纯英文路径**（当前 `C:\Users\Want\dev\ShiGuang`）。放在含中文的目录里：
> - 主构建可加 `android.overridePathCheck=true` 绕过；
> - 但**单元测试**会因 Java 的 URLClassLoader 无法读取含非 ASCII 字符的路径而全部 `ClassNotFoundException`。所以别搬回中文目录。

## 安装到手机

1. 把 `app-debug.apk` 传到手机（微信/网盘/USB 均可），点击安装（系统会要求开启「未知来源」）。
2. 打开「拾光」→ 引导页选你在意的主题、常用 App，按提示去「通知使用权」里授权。
3. 可选：相册权限（图片自动归集）、无障碍（聊天长文留档）。
4. 回微信/QQ 正常聊天即可。App 会在状态栏显示「拾光正在守护美好瞬间」。

## 用法速览

| 想做什么 | 怎么做 |
|---|---|
| 被「值得记录」的通知打断 | 点它 → 已收藏；或忽略 |
| 想让高分瞬间自动入库 | 「我」页 → 收藏判断 → 打开「授权后自动记录」 |
| 有图的瞬间没收到图 | 在微信里长按图片「保存到相册」→ App 自动归集 |
| 看随机回忆 | 首页「✨ 随机翻开一段回忆」 |
| 看那年今日 | 首页 → 那年今日；或日历页右上角 |
| 导出回忆 | 「我」→ 数据 → 导出 HTML（自包含一本「美好之书」）/ JSON |
| 不用真机试核心链路 | 「我」页底部「调试 · 模拟消息」（仅 debug 版）→ 选类型和内容投喂 |

## 权限说明

- **通知使用权**：识别聊天里的美好（核心）。
- **相册**：把长按保存的图自动归集（可选）。
- **无障碍**：读取聊天界面长文（可选，可在设置关闭）。
- **无 INTERNET 权限**：全离线。

## 技术栈

Kotlin · Jetpack Compose (Material 3) · Room · DataStore · WorkManager · Coil（仅本地图）
通知监听 + 无障碍 + 相册观察 + 前台保活服务，全部系统原生能力。

## 已知限制（诚实清单）

- 微信/QQ 的图片、语音**音频文件**无法从通知直接取得 → 图片靠相册归集、语音记事实+备注。
- 通知文本可能被系统截断；完整长文依赖无障碍且需正在聊天界面。
- 国产 ROM（MIUI/EMUI 等）后台风控可能杀进程 → 建议锁屏保护里给「拾光」加白；前台服务已尽力拉高存活率。
- 无真机阶段用「调试 · 模拟消息」验证的是核心管线；微信/QQ 真实通知字段细节需真机后微调解析器（已做通用兜底）。
