# 拾光 ShiGuang ✨

> 一本为你留住生活小瞬间的「时光手账」。把此刻变成以后的回忆，一次一句话、一张图，都算。

拾光是一款**纯本地、零联网**的 Android 记录 App：没有账号、没有云端、没有广告，你的每一段记录只存在你的手机里。
它不像日记那样逼你写满一整页——**一句话、一次心情、一张照片**，都是值得收下的光。

## 它是什么样

- 🖊️ **随手记**：全屏便签式编辑器，不朴素；支持**一次多张图**、**补记过去的日期**、一键「写给自己」（自动星标）。
- 😊 **心情印章**：点一个表情，今天就盖了章；攒成你的心情日历。
- 🌟 **成长系统**：12 级「拾光成长之路」+ 经验点（**每段记录或一次心情盖章 = 1 XP**）+ 连续记录天数 + 升级时的全屏庆祝和彩虹粒子。
- 📦 **时光宝盒**：把某段瞬间预约到 1 个月 / 半年 / 1 年后，到点推送「时光宝盒打开啦」，与未来的自己重逢。
- 📖 **本周杂志 / 📊 月度报告**：每周末自动生成「本周报纸」；每月一键看《常和谁 / 心情分布 / 最暖的那句话》。
- 🎴 **随机翻卡**：3D 双面翻转 + 内容逐块浮现 + 烟火彩虹，待机也灵动。
- 🗓️ **多元回看**：时间线日记 / 相册墙 / 日历（选中日多图横滑）/ 那年今日 / 关键词·人物检索 / 联系人名单直达某人的全部记录。
- 💾 **导出**：HTML(自包含「美好之书」) / JSON；本地头像、昵称、签名我的页。

**隐私承诺**：不申请 `INTERNET` 权限，不联网、不上传、不追踪。唯一的系统能力是「通知」——用于每天 21:30 提醒你抽一段回忆（可关）。

## 构建

环境：JDK 17+、Android SDK（platform 34 / build-tools 34.0.0）。自带 Gradle wrapper。

```
./gradlew :app:assembleRelease        # 产出 app/build/outputs/apk/release/app-release.apk
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest      # 评分引擎/等级 等纯逻辑单测
```

> 作者在 `C:\Users\Want\dev\ShiGuang` 用本机 `build.bat` 一键构建（内置个人 JDK/SDK 路径，未入库）。

## 安装

1. 把 `app-release.apk` 传到手机（微信/QQ/网盘/USB），开启「未知来源」安装。
2. 打开 → 完成简短引导 → 就可以开始记录。

## 权限

- **通知**：每日回忆提醒（可选，可在「我 → 守护」关闭）。
- **无** INTERNET、相册其实不需要（用的是系统「照片选择器」，App 自己拷贝到私有目录）。

## 技术栈

Kotlin · Jetpack Compose (Material 3) · Room · DataStore · WorkManager · Coil（本地限幅加载，防大图 OOM）
内置崩溃日志（闪退后可在「我 → 诊断」查看/复制，便于排查）。

## 已知边界（诚实清单）

- 语音「秒记」尚未接入（预留接口）。
- 多图会在一条瞬间内平铺展示；相册墙按图拆块。
- 一切本地：换机需手动导出导入。
